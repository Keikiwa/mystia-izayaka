# 《东方夜雀食堂》全玩法/功能完整描述（复刻需求文档级，纯内容描述，不写正式文档模板）
游戏核心循环：**以“一天”为最小时间单元，分为【白天·幻想乡地图探索准备阶段】+【夜晚·食堂营业阶段】；完成一个区域的债务目标即可解锁下一区域，推进主线剧情，最终完成全部区域并达成结局。无弹幕战斗，全部玩法围绕食材、菜谱、客人偏好、经营管理、NPC好感羁绊展开**

## 一、全局基础框架与时间系统
1. 时间模型
    - 白天地图行动：每次采集、交互、对话消耗**固定半小时**，左上角显示当日剩余白天时长；可手动点击【直接入夜】跳过剩余白天，直接进入夜间营业。
    - 夜间营业：连续实时流程，营业过程不消耗真实世界天数；营业结束结算，才算游戏内一天完成，**仅闭店结算时自动存档**，营业中途不能存档。
    - 跨区域章节：本体一共5大经营区域：兽道→人间之里→魔法森林→妖怪之山→地灵殿；每个区域有固定债务目标，还清债务解锁下一区域。DLC追加额外区域、角色、菜谱。
2. 难度选择：开局选定，游戏内不可切换，影响客人数量、稀客出现概率、营收目标、惩罚符卡强度。
3. 主角（米斯蒂娅）成长系统
    - 经验等级：营业获得经验升级。升级属性：增加可摆放餐桌数量、厨具数量、餐盘携带上限；提升**夜雀之歌**触发概率与持续时长。
    - 夜雀之歌（核心被动演出机制）：营业期间概率触发，类似简易音游判定，按提示按键；判定成功获得全局经营增益（人气上涨、小费加成、加快上菜速度）；判定失败无惩罚，仅不获得加成。唱片收集系统解锁更多BGM与音游曲目（DLC追加独立音游挑战模式）。
    - 外观换装：家中地下室衣柜，解锁服装皮肤，纯外观无属性。
4. 伙伴雇员系统
    - 随剧情解锁最多5名助手，**营业前最多上阵3人**。
    - 雇员分工自动执行：自动制作普通菜品、自动给普通客人上酒水、自动收拾空餐盘。
    - 雇员不会处理【稀客（特殊东方角色NPC）】的订单，稀客的菜品+酒水必须由玩家亲手制作、亲手送上。每个雇员自带专属加成：小费加成、烹饪加速、食材节约等。营业前可自由选择上阵伙伴组合。

## 二、白天阶段：幻想乡地图探索、资源准备、NPC羁绊
白天阶段目标：采集食材、购买食材酒水、和NPC对话提升好感、接取任务、学习菜谱、在自家厨房预制菜品。
1. 地图自由移动交互
    - 像素大地图，可奔跑，奔跑速度随等级提升。地图内分布采集点、商店、NPC、场景交互物。
    - 采集点：地图固定位置刷新食材，不同区域产出专属食材；部分采集点有季节/刷新周期限制。交互一次消耗半小时，获取对应食材。
2. 商人购买系统
    - 地图常驻商人（香霖堂等）：售卖食材、酒水、少量菜谱、道具。商品库存每日刷新，不同地图商人售卖货品池不同；可获得折扣券降低采购价格。
    - 物品仓库：独立背包，分为食材、酒水、菜谱、道具四类；有容量上限，库存满了无法拾取新物品。可查看物品详情、标签、数量。
3. NPC好感&羁绊系统（非常核心）
    - 普通NPC、稀客NPC均可提升好感。白天地图找到NPC对话，每次对话少量增加好感；夜间营业提供满意菜品大幅提升好感。好感分段等级。
    - 好感奖励：解锁新菜谱、解锁委托采集功能（好感满后可委托NPC隔天自动送来指定食材，减少手动采集）、解锁CG、解锁夜间【主动邀请稀客到店】功能。
    - 笔记图鉴：自动记录所有客人的喜好标签、厌恶标签、预算、口味备注；初次遇见稀客时信息不全，随好感提升逐步补全情报。
4. 菜谱学习、预制厨房功能（家里的后厨）
    - 菜谱结构：每道菜包含**基础食材配方 + 菜品标签（tag系统）**。标签是整个游戏的核心匹配规则，例如：实惠、辣、水产、肉、甜、猎奇、中华、重油等。
    - 菜谱获取渠道：NPC好感奖励、商人购买、剧情任务奖励、稀客满足后奖励。
    - 预制菜品：白天在家使用厨具提前制作菜品，存入保温箱。预制菜品夜间营业可以直接上菜，省去营业中烹饪时间，应对客流高峰。保温箱有存储上限；当日预制菜品仅限当晚营业使用，隔夜无法保留。
    - 加料改造机制：菜品制作阶段，基础菜谱做完后，可以额外添加其他食材，**追加额外标签**。用于微调菜品，匹配稀客的喜好tag，规避厌恶tag。加料会增加成本，部分加料会产生负面标签。
    - 厨具系统：不同厨具对应不同品类菜品（烤炉、煮锅、油锅、蒸屉等）；营业前需要布置到食堂后厨，没有对应厨具则当晚无法制作该分类菜品。厨具可升级/解锁更多种类。
5. 任务系统
    - 主线任务：区域还债、剧情推进；支线任务：NPC委托，采集物品、制作指定菜品、招待特定客人，奖励金币、菜谱、食材。任务面板可查看目标、进度、奖励。
6. 开店前配置（白天结束、进入夜晚营业前的准备面板）
    - 选择营业场地、布置餐桌数量、摆放厨具、配置上架菜单（选定今晚可售卖的菜品清单）、酒水架配置酒水、选择上阵雇员。
    - 可选择【邀请函】主动邀请特定稀客今晚到店，消耗对应道具。

## 三、夜晚阶段：食堂实时营业（核心经营玩法）
场景：移动夜雀居酒屋，包含后厨、餐桌、酒水台。营业是实时流程，客人分批进场。
### 3.1 客人类型分为两类：普通客人、稀客（特殊角色NPC）
1. 普通客人
    - 进店自动点餐，需求简单，只看菜品基础tag、价格。雇员自动处理制作、上酒水，玩家可以介入帮忙。
    - 满意度影响：给符合口味菜品→正常付费+小费；不符合口味→不付小费，少量降低人气。预算有限，太贵菜品会拒绝。
2. 稀客（东方角色，核心博弈点）
    - 进店不会直接点单，给出文字提示，需要玩家上前交互读取需求。需求由**喜爱标签集合 + 禁止厌恶标签 + 预算上限**构成，同时需要配套酒水。
    - 满意度评级机制：
      - 完美满足：全部喜爱tag命中，**没有触发任何厌恶tag**，触发专属CG。客人发放【奖励符卡】，高额小费、额外金币、道具、菜谱，同时累积稀客combo。
      - 部分满足：部分tag命中，无CG，正常付费，少量好感。
      - 踩厌恶标签/严重不符合：客人不满，触发【惩罚符卡】，造成负面效果：扣除人气、没收小费、清空当前combo、增加后续客人挑剔程度、直接离场不付钱。
    - 稀客订单必须玩家亲手完成：亲手做料理、亲手取酒水、亲手送到客人桌上，雇员不会代为服务稀客。部分稀客会连续多次下单。

### 3.2 符卡系统（营业全局buff/debuff）
- 奖励符卡（稀客满意后发放）：临时全局增益。例如：全场小费翻倍、食材消耗减半、人气快速上涨、稀客出现率提升、餐桌临时扩容、夜雀之歌更容易触发。
- 惩罚符卡（稀客不满意触发）：全局负面效果，例如人气暴跌、所有客人预算降低、菜品价格被压低、combo清零。
- Combo连锁机制：连续成功招待稀客，叠加combo倍率，营收与奖励持续放大；一旦招待失败，combo直接重置归零。

### 3.3 营业内基础操作
- 后厨烹饪：选中菜谱，消耗食材，占用厨具，等待烹饪时间；可中途加料修改tag。
- 餐盘携带：玩家携带餐盘，存放做好的菜品，餐盘数量上限随主角等级提升。
- 酒水台：单独存储酒水，酒水有独立标签；稀客对酒水同样有喜恶标签，酒水选错也会扣分。
- 餐桌交互：上菜、收空盘子、和客人对话读取需求。
- 人气系统：全局指标，影响客流量、稀客刷新概率；上菜快、客人满意、夜雀之歌成功都会提升人气；客人不满、惩罚符卡降低人气。人气归零会造成营业收入大幅缩水。

### 3.4 营业结算（闭店阶段）
营业结束后弹出结算面板：
- 统计：总收入、食材成本、净利润、招待普通客人数、稀客数量、最高combo、人气峰值、小费总额。
- 扣除区域当期债务，更新债务进度。
- 获得主角经验，解锁奖励。
- 保存当日全部进度，写入存档，进入第二天白天。

## 四、图鉴、收集、成就系统
1. 笔记图鉴
    - 客人图鉴：记录所有客人（普通+稀客）喜恶tag、预算、对话CG，随好感逐步解锁。
    - 菜谱图鉴：收集全部菜谱，查看配方、标签、售价。
    - 食材&酒水图鉴：收集所有原料与酒类，来源、标签。
2. 成就系统：全局成就，覆盖剧情、经营挑战、菜谱全收集、客人好感满值、高combo营业、特定符卡组合达成等。
3. 唱片收集：收集幻想乡BGM唱片，解锁背景音乐、夜雀之歌音游曲目，DLC提供独立音游挑战模式，分多难度。

## 七、规则边界
1. 没有角色战斗、弹幕射击；全部冲突是经营层面（客人不满、惩罚符卡）。
2. 预制菜品仅限当日夜晚使用，不可跨天囤积。
3. 稀客的tag匹配逻辑是“标签集合匹配”，不是固定唯一菜品，玩家可以自由改造菜品达成目标，这是核心策略点。
4. 雇员仅自动化普通客人，稀客强制玩家手动操作，保留操作压力。
5. 存档规则硬性约束：**只有营业结束结算时才自动存档，白天/营业中无法手动保存**。

## 八、全局经济规则
- 货币：幻想乡金币；收入来源：餐费、酒水费、小费、稀客符卡奖励；支出：食材酒水采购、区域债务偿还。
- 债务机制：每个章节有硬性债务目标，需要累计营业净利润还清；还清后解锁下一地图剧情。债务不会随天数自然增长，只看累计盈利。
- 定价规则：每道菜有基础售价；人气、符卡、combo、客人预算共同决定客人愿意支付的实际价格；超出客人预算的菜品会导致客人给出最低评价, 稀客还会触发惩罚符卡
